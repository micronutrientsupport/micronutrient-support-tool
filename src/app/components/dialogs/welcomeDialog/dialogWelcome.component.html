The Micronutrient Action Policy Support (MAPS) tool provides information on nutrients in food systems for nations in sub-Saharan Africa. We have co-created this web-hosted tool to estimate micronutrient deficiencies and explore pathways to improve nutrition. Features available include QuickMAPS and cost-effectiveness modelling of interventions.

We provide this using our latest version of curated data. Please take care to review the suitability of these data for your intended use(s). We are happy to receive feedback on the data itself or the model features

We would be delighted to receive your views on the ease of use of the tool before you leave our site, using the button at the bottom right of the page. We also have a ‘Submit Feedback’ button on the right side of the screen – this can be used for feedback on content on the specific part of the tool you are looking at, at any time.

If you would like to request, or up-vote, features operationalised in the tool, please use the Feature Request Portal to do this.

You can return to this dialog at any point using the icon in the bottom right of the page.
