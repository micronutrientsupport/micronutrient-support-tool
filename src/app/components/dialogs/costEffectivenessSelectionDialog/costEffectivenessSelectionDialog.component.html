MAPS Intervention Templates

MAPS provides a collection of template interventions which can be customised for your use case. These are prepopulated with expert solicted values (which can still be overriden). For nations which doe not currently have a dedicated model, the most appropriate nation with a pre-populated model can be selected and used as a basis for the new model.

Note: You can choose to model any combination of focus micronutrient and food vehicle/crop. However, the user is responsible for ensuring the technical feasibility of the combination.
Effectiveness and Cost-Effectiveness can only be modeled for nations with population and HCES consumption data within the MAPS Tool. Costs can be modeled for all interventions.
